## 🚀 Featured Projects


### 🧠 AI Upskilling Agent

**A personalized AI agent that continuously builds and adapts your learning roadmap**

An intelligent upskilling assistant that maintains a learner profile containing **skills, subjects studied, completed courses and interests**.

The system uses this evolving profile to:

- Identify skill gaps
- Recommend what to learn next
- Create a personalized learning timeline
- Suggest relevant learning resources
- Continuously adapt the roadmap as the learner progresses

`Agentic AI` `Personalization` `LLMs` `RAG` `Learning Roadmaps`

### 👻 GhostPush

**AI-powered Code Repository Sync Manager**

GhostPush is a developer tool that automates the process of syncing coding solutions from platforms like **LeetCode, GeeksforGeeks and TUF** to GitHub.

It uses **AI agents and MCP-based tools** to understand, process and organize solutions before committing them to the appropriate repository, while keeping **credentials and sensitive data locally** under the user's control.

`Python` `LangGraph` `MCP` `AI Agents` `GitHub` `Automation` `Developer Tools`
